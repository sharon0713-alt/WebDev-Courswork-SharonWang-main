# Unit 8 Reflection
In Unit 8, I learned advanced CSS for layout and responsive design. First, I learned to use div as a container and class attributes to apply the same styles to multiple elements. This made my code cleaner and easier to maintain.

Next, I learned the box model - every element has content, padding, border, and margin. Padding is inside the border, margin is outside. I also learned position properties: relative, absolute, fixed, and sticky for different placement needs.

Then, I learned the display property. Block elements take full width, inline elements stay on the same line, inline-block combines both, and none hides elements completely.

Finally, I learned responsive design versus adaptive design. Responsive design uses media queries to adjust one layout to all screen sizes. I used @media (max-width: 768px) to make a horizontal navigation bar become vertical on mobile phones. Unit 8 taught me to create websites that look good on any device.
