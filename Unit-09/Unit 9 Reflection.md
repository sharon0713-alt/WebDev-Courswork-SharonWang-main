# Unit 9 Reflection
In Unit 9 I learned the basics of JavaScript and how it brings interactivity to websites. JavaScript is a programming language that runs within the web browser. HTML gives structure, CSS gives style, JavaScript gives behavior, such as buttons, pop-ups and dynamic content.

I learned about input and output. The input is given by users, for example by clicking a button. Output is the response from the website, such as a pop-up message. I learned how to write functions( reusable blocks of code ). I also learned how to make buttons using the HTML button tag and assign JavaScript functions with the onclick event attribute.

Finally, I learned to modify HTML content using JavaScript. I used getElementById to find an element and innerHTML to change its content. For example, I made a button that changes text from "Hello World!" to a smiley face without reloading the page.

Unit 9 gave me the skills to make my websites interactive and dynamic. JavaScript brings web pages to life. I suppose I gain the most in this unit.
